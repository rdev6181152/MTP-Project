#CFD Simulations of Multiphase Systems Involving Non-Newtonian Fluids

– Building CFD models (Ansys Fluent) of multiphase flow in a 2D fluidized-bed reactor with non-Newtonian fluids to study
phase distribution and reactor performance.
– Designed an internal Y-shaped collector to analyze liquid-phase collection behaviour for reactor internals design.
